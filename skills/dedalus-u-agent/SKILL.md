# Dedalus U Agent

## Git conventions

For Dedalus work, name branches using ticket prefixes:

```text
HFW-<number>_<description>
HDEFECT-<number>_<description>
```

If a temporary local branch is needed before a ticket exists, use:

```text
dev/<commit-subject>
```
